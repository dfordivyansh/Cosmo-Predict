# 🌠 Project Overview

**CosmoPredict** is an advanced **AI-powered Space Weather Monitoring & Asteroid Risk Analysis Platform** developed as a **B.Tech Final Year Major Project**.

The platform integrates:

✅ Real-Time NASA APIs  
✅ NOAA Space Weather APIs  
✅ AI & Machine Learning Models  
✅ LSTM Forecasting Systems  
✅ Asteroid Hazard Analysis  
✅ Secure AWS Cloud Deployment  

to provide intelligent monitoring of:

- 🌍 Geomagnetic Storms  
- ☄️ Near-Earth Asteroids  
- 🌞 Solar Activity  
- 📡 Space Weather Events

# ⚙️ Installation Guide

## 1️⃣ Clone Repository

```bash
git clone https://github.com/dfordivyansh/Cosmo-Predict.git
```

---

# 2️⃣ Backend Setup (Django)

## Navigate to Backend

```bash
cd cosmo-backend
```

## Create Virtual Environment

```bash
python -m venv venv
```

## Activate Environment

### Windows

```bash
venv\Scripts\activate
```

---

## Install Dependencies

```bash
pip install -r requirements.txt
```

---

## Run Migrations

```bash
python manage.py migrate
```

---

## Create Superuser

```bash
python manage.py createsuperuser
```

---

## Start Django Server

```bash
python manage.py runserver
```

### Backend URL

```bash
http://127.0.0.1:8000
```

---

# 3️⃣ Frontend Setup (React + Vite)

## Navigate to Frontend

```bash
cd cosmo-frontend
```

---

## Install Packages

```bash
npm install
```

---

## Start Development Server

```bash
npm run dev
```

### Frontend URL

```bash
http://localhost:8080
```
